# HAM10000 Skin Lesion Classifier — Results & Discussion

---

## 1. Project Summary

This project builds and compares three deep learning classifiers for
dermoscopic skin lesion classification on the HAM10000 dataset (10,015 images,
7 classes). The clinical motivation is clear: the three malignant classes
(melanoma, basal cell carcinoma, actinic keratosis) are also the minority
classes, meaning a naive classifier that always predicts the majority class
(*melanocytic nevi*) achieves ~67% accuracy while missing every cancer.
Accuracy is therefore a dangerously misleading metric; this project reports
**macro-F1 and recall on malignant classes** as the primary results throughout.

A from-scratch baseline CNN is compared against fine-tuned ResNet18 and
EfficientNet-B0 under identical conditions (same lesion-level splits,
same class-weighted loss, same training loop). Grad-CAM heatmaps are
generated in Stage 5 as a qualitative diagnostic aid.

> **Split note:** All reported results use a **lesion-level split**
> (via `make_lesion_splits()` in `src/preprocessing.py`). The function
> collapses the metadata to one row per `lesion_id`, stratifies on `dx`,
> and maps every image back to its partition — no lesion crosses the
> train/test boundary.

All models are evaluated on the same held-out test set (15% of HAM10000,
stratified by `dx`). Class weights computed from the training partition are
applied to CrossEntropyLoss for all models. The test set is evaluated
**once**, after training completes, using the best checkpoint (lowest
val loss). Early stopping and LR scheduling use the validation set only.

### 2.2 Methodology notes

**Accuracy is misleading on this dataset.** A model that always predicts
`nv` (66.9% of images) achieves ~67% accuracy while failing on every
malignant case. Macro-F1 and per-class recall on the malignant classes
(mel, bcc, akiec) are the metrics that matter.

**Class weighting — a deliberate preventive decision, not a reactive fix.**
HAM10000 is 67% `nv`. Without class weighting, CrossEntropyLoss's gradient
steers the model toward predicting `nv` for everything — a well-documented
failure mode on heavily imbalanced datasets. Inverse-frequency weights
(`w_c = N / (C × n_c)`) are computed from the training partition and applied
to the loss from the first training run of every model.

**Why lesion-level split?** HAM10000 contains multiple images per lesion
(different zoom levels, lighting). An image-level split can put images of the
same lesion in both train and test, giving the model an implicit look at test
lesions during training. The lesion-level split eliminates this. An optional
image-level run (`split_mode="image"`) is kept for comparison only.

## 3. Tradeoff Analysis

### 3.1 Architecture overview

| Model | Approx. params | Notes |
|---|:---:|---|
| Baseline CNN | ~0.4M | Trained from scratch — 4× ConvBlock, GAP, Dropout(0.5), Linear |
| ResNet18 | ~11.2M | ImageNet pretrained; final Linear replaced (512→7) |
| EfficientNet-B0 | ~4.0M | ImageNet pretrained; classifier head replaced (1280→7) |

**Metric comparison and tradeoff discussion will be written here once
`outputs/metrics/*.json` files are committed.**

### 3.2 Training setup

Both transfer models are trained with a two-speed Adam optimizer:
backbone `lr = 1e-4` (protecting pretrained features) and head `lr = 1e-3`
(full-speed updates for the new classifier). Both use early stopping with
patience=7 and a ReduceLROnPlateau scheduler (patience=3, factor=0.5).
The baseline CNN uses a single Adam lr=1e-3.

Transfer models converge faster than a from-scratch CNN because the backbone
starts with ImageNet-pretrained features — useful low-level detectors do not
need to be relearned from scratch. This is a practical advantage on Colab
free tier (~4 hour GPU sessions).

**Caveat:** Grad-CAM shows which regions positively contributed to the
predicted class score at a coarse spatial resolution. It is a qualitative
diagnostic aid. Focus on lesion regions is a positive sanity check; it
does not prove the model understands lesion structure or will generalise
to out-of-distribution images.

## 5. Limitations

**1. Dataset size and residual class imbalance**
10,015 images across 7 classes, with the rarest class (*Dermatofibroma*)
having only ~115 images total (~80 after the 70/15/15 split). Class
weighting mitigates majority-class collapse but cannot compensate for
fundamental data scarcity in rare classes.

**2. This is a research project, not a validated diagnostic tool**
The models trained here have not undergone clinical validation and must not
be used for medical decision-making. Dermoscopic image classifiers require
rigorous prospective clinical evaluation, regulatory approval, and integration
into a clinical workflow with human oversight before any clinical use.

**3. No external test set — unknown generalisation**
All evaluation uses HAM10000's own held-out split. The training, validation,
and test images all come from the same acquisition protocol, dermatoscope
type, and patient population (predominantly European). Performance on images
from different cameras, lighting conditions, or patient demographics is
unknown.

**4. Lesion_id is the best available grouping, not patient-level grouping**
HAM10000's metadata contains no patient identifier. Different lesions from
the same patient may appear in different splits. This is the best split
possible given the available metadata; it does not guarantee complete
patient-level independence.

**5. Image artifacts**
The dataset contains known artifacts: hair crossing lesions, ruler markings,
ink dots, and dark vignettes from the dermatoscope lens. Whether the models
rely on these artifacts will be assessed qualitatively in Stage 5
(Grad-CAM, not yet run).

## 6. Future Work

**1. Ensemble of transfer models**
Averaging predictions from ResNet18 and EfficientNet-B0 is likely to improve
robustness on minority classes without additional training. Ensemble methods
consistently outperform individual models in dermoscopy classification
literature and are a natural next step.

**2. External validation on ISIC 2019/2020 data**
Evaluating the trained models on ISIC 2019 or 2020 test sets (without
retraining) would give a more honest estimate of out-of-distribution
generalisation — the standard benchmark before clinical deployment.

**3. Focal loss comparison**
This project used class-weighted CrossEntropyLoss. Focal loss (Lin et al.,
2017) dynamically down-weights easy examples during training and is reported
to improve minority-class recall in some dermoscopy papers. A direct A/B
comparison on the same splits would cleanly quantify the difference.
