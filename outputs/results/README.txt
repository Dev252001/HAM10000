JSON files in this directory are generated by running the Colab notebooks.
They are not committed to git because they depend on a GPU training run.

Expected files (created by the save cell at the end of each training notebook):
  baseline_cnn_results.json     — Stage 3 output
  resnet18_results.json         — Stage 4 output
  efficientnet_b0_results.json  — Stage 4 output

To regenerate the README results table from these files, run:
  python scripts/results_table.py
