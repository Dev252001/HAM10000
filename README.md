## Evaluation protocol

All results use a **lesion-grouped, class-stratified 70/15/15 split** (`split_mode="lesion"`, `random_state=42`). The function `make_lesion_splits()` in [`src/preprocessing.py`](src/preprocessing.py) collapses the metadata to one row per `lesion_id`, performs two stratified `train_test_split` calls on the lesion IDs (stratified on `dx`), then maps every image back to its partition. This guarantees no lesion appears in more than one split.

Checkpoints and early stopping use the validation set exclusively; the test set is evaluated once, after training completes, using the best checkpoint (lowest val loss). Class weights are computed from the training partition only (`w_c = N / (C × n_c)`).

Primary metric: **macro-F1** (treats all 7 classes equally, not skewed by the majority class). Secondary: per-class recall on the three malignant classes (mel, bcc, akiec), since false negatives on cancer are the clinically costly errors.

The image-level `make_splits()` function is retained for reference. An optional secondary run with `split_mode="image"` can be used to quantify how much lesion leakage inflates scores; those results are labelled by split mode in the filename (`*_image_seed42.json`).

## Dataset

**Source:** [Kaggle — Skin Cancer MNIST: HAM10000](https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000)  
**Size:** 10,015 images · 7 classes · heavily imbalanced

| Code | Full Name | Malignant | Count | % |
|------|-----------|:---------:|------:|--:|
| `nv` | Melanocytic Nevi | — | ~6705 | 66.9% |
| `mel` | Melanoma | ⚠️ | ~1113 | 11.1% |
| `bkl` | Benign Keratosis | — | ~1099 | 11.0% |
| `bcc` | Basal Cell Carcinoma | ⚠️ | ~514 | 5.1% |
| `akiec` | Actinic Keratosis / IEC | ⚠️ | ~327 | 3.3% |
| `vasc` | Vascular Lesion | — | ~142 | 1.4% |
| `df` | Dermatofibroma | — | ~115 | 1.1% |

Image-level imbalance ratio: `nv` / `df` ≈ 6705 / 115 ≈ **58:1** (from the published counts above).  
Lesion-level ratio: computed and printed by `scripts/make_results_table.py` once the metadata CSV is available.

## Notes

- **Split:** 70/15/15 stratified on `dx`, grouped by `lesion_id`. The rarest class (`df`, 115 images) needs ~17 images per eval set for stable recall — 80/10/10 would leave only ~11.
- **Class weights** computed from the training partition only (`w_c = N / (C × n_c)`), passed to `CrossEntropyLoss`. Applied from the first training run of every model.
- **All reported results use the lesion-level split.** An optional image-level run can be added for direct comparison; those files are named `*_image_seed42.json`.
- **Grad-CAM (Stage 5, not yet run).** Heatmaps will show which image regions influenced each prediction. This is a qualitative diagnostic aid; focus on lesion regions is a positive sanity check, not proof of generalisation. Results will be written to `outputs/figures/` and described in `outputs/RESULTS.md` after the notebook is run.
